# Fnord Blast

Un clone inspiré de *Peggle Blast*, centré sur le pouvoir de **Fnord** : voir les deux prochains rebonds de la bille et enflammer les pegs au contact.

## Jouer

Ouvre `index.html` dans un navigateur.

- **Souris** : viser, **clic** : tirer
- **F** : activer / couper le pouvoir de Fnord
- **R** : recommencer

## Version application (Windows)

```bash
cd app
npm install
npm run pack
```

L'exécutable est généré dans `app/dist/FnordBlast-win32-x64/FnordBlast.exe`.
